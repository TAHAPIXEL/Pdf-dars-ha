### چه چیزی داخلش هست

- **درس‌نامهٔ کامل برای هر فصل** — با جدول، فرمول، نکته‌های آزمونی و «نکات ویژهٔ آزمون»
- **بانک پرسش با پاسخ تشریحی** — هر پرسش توضیح می‌دهد چرا پاسخ درست است
- **بدون قلب و بدون محدودیت** — آزمون‌ها را بی‌نهایت بار تکرار کن
- **سیستم XP و استریک روزانه** — پیشرفت با `localStorage` ذخیره می‌شود، بدون حساب کاربری
- **ریسپانسیو کامل** — موبایل ۳۲۰ پیکسل تا دسکتاپ
- **فونت‌های Abar** — سه خانواده در نقش‌های متفاوت، تبدیل‌شده به `woff2`

## ساختار مخزن

```
.
├── index.html                 ← صفحهٔ اصلی درس‌یار
├── lessons/                   ← ده محیط یادگیری (۴۰ صفحه)
├── assets/
│   ├── fonts/abar/            ← فونت‌های Abar (woff2)
│   ├── css/                   ← fonts.css + app.css
│   ├── js/app.js              ← موتور مشترک
│   └── data/                  ← محتوای ۱۰ درس
├── tools/build.py             ← سازندهٔ صفحات
├── docs/                      ← مستندات
└── پایه-نهم/                  ← PDF کتاب‌ها
```

## اجرای محلی

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

سایت ایستاست و روی GitHub Pages هم بدون تنظیم اضافی کار می‌کند.
