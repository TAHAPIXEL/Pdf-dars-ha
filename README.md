# Pdf-dars-ha — کتاب‌های درسی پایه نهم

فایل‌های PDF کتاب‌های درسی **پایه نهم (دوره اول متوسطه)** برای **سال تحصیلی ۱۴۰۵–۱۴۰۶**.

در این مخزن فقط کتاب‌هایی قرار گرفته‌اند که **از آن‌ها آزمون گرفته می‌شود** (امتحانی/قابل آزمون در مدارس ایران). کتاب‌های غیرامتحانی مثل فرهنگ و هنر، آمادگی دفاعی و کار و فناوری عمداً گذاشته نشده‌اند.

## توضیحات

- فایل‌ها نسخه کامل کتاب‌های درسی هستند و صفحات به ترتیب اصلی کتاب (فصل‌به‌فصل و درس‌به‌درس) پشت سر هم قرار گرفته‌اند.
- کتاب‌های **نگارش** و **کتاب کار زبان انگلیسی** از کتاب‌های همراه فارسی و انگلیسی هستند و در آزمون‌ها (به‌ویژه امتحانات نوبت) به‌عنوان بخشی از درس مربوطه پرسش دارند، به همین دلیل در فهرست آمده‌اند.
- صفحات ابتدایی غیردرسی (سخنی با معلم، شناسنامه کتاب) در برخی کتاب‌ها موجود نیست؛ محتوای درسی کامل است.

## منبع

فایل‌ها بر پایه نسخه‌های منتشرشده کتاب‌های درسی پایه نهم (سال تحصیلی ۱۴۰۵–۱۴۰۶) گردآوری شده‌اند.
