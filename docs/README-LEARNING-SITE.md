## چطور کار می‌کند

هر درس چهار صفحه دارد:

```
lessons/<درس>/
├── index.html    ← مسیر یادگیری (درس‌نامه‌ها + آزمون‌ها به ترتیب)
├── all.html      ← همهٔ درس‌نامه‌ها پشت سر هم (مطالعهٔ پیوسته)
├── lesson.html   ← خواندن یک درس‌نامه  (?id=c1)
└── quiz.html     ← آزمون یک درس یا آزمون جامع  (?id=c1 | ?all=1)
```

**چرخهٔ یادگیری:** درس‌نامه را بخوان → «خواندم ✓» را بزن → آزمون بده → پیشرفت ثبت می‌شود.

## ویژگی‌ها

- **بدون قلب و بدون محدودیت** — آزمون‌ها را بی‌نهایت بار می‌توان تکرار کرد. بهترین نتیجه ثبت می‌شود، آخرین نتیجه هم نمایش داده می‌شود.
- **سیستم XP** — هر درس خوانده‌شده ۱۰ XP و هر پرسش درست ۴ XP (به‌علاوهٔ ۱۸ XP پاداش برای قبولی بالای ۷۰٪).
- **استریک روزانه** — روزهای پیوستهٔ فعالیت ثبت می‌شود.
- **ذخیره‌سازی محلی** — پیشرفت در `localStorage` مرورگر ذخیره می‌شود، بدون نیاز به حساب کاربری و بدون ارسال داده به جایی.
- **ریسپانسیو کامل** — از موبایل ۳۲۰ پیکسل تا دسکتاپ.
- **دسترس‌پذیری** — احترام به `prefers-reduced-motion`، کنتراست کافی، ساختار معنایی.

## سیستم تایپوگرافی Abar

سه خانوادهٔ فونت، هر کدام برای نقش مشخص:

| خانواده | نقش | وزن‌های استفاده‌شده |
|---------|------|---------------------|
| **Abar High** | تیتر اصلی صفحه، صفحهٔ نتیجه، شماره درس‌ها | ۸۰۰، ۹۰۰ |
| **Abar Mid** | دکمه‌ها، برچسب‌ها، زیرتیترها، نام درس، متن سؤال | ۶۰۰، ۷۰۰، ۸۰۰ |
| **Abar Low** | متن درس‌نامه، گزینه‌ها، توضیح‌ها | ۴۰۰، ۶۰۰، ۷۰۰ |

فونت‌ها از `woff` به `woff2` تبدیل شده‌اند (۲۰٪ حجم کمتر) و در `assets/fonts/abar/` قرار دارند.

## ساختار پروژه

```
.
├── index.html                 ← سایت جامع: ده کارت درس + دکمهٔ ورود
├── lessons/<درس>/             ← ده محیط یادگیری مستقل (۴۰ صفحه)
├── assets/
│   ├── fonts/abar/            ← فونت‌های Abar (woff2)
│   ├── css/
│   │   ├── fonts.css          ← تعریف @font-face
│   │   └── app.css            ← سیستم طراحی کامل
│   ├── js/app.js              ← موتور مشترک (ذخیره‌سازی، آزمون، مسیر)
│   └── data/<درس>.js         ← محتوای هر درس (درس‌نامه + بانک پرسش)
├── tools/build.py             ← سازندهٔ صفحات درس‌ها
├── پایه-نهم/                  ← PDF کتاب‌های درسی
└── README.md
```

## توسعه

برای بازسازی صفحات درس‌ها پس از تغییر فایل‌های داده:

```bash
python3 tools/build.py
```

محتوای هر درس در `assets/data/<درس>.js` است:

```js
window.CONTENT["math"] = {
  key, name, icon, accent, accentDeep, lede,
  lessons: [{ id, n, title, page, body }],
  quizzes:  { c1: [{ q, opts, a, why, tag }] }   // a = اندیس پاسخ درست
};
```

افزودن درس جدید: فایل داده بساز، کلیدش را در `SUBJECTS` در `tools/build.py` و `ORDER` در `index.html` اضافه کن، سپس اسکریپت سازنده را اجرا کن.

## اجرا

سایت کاملاً ایستاست. کافی است در پوشهٔ ریشه یک سرور محلی اجرا کنی:

```bash
python3 -m http.server 8080
```

سپس `http://localhost:8080` را باز کن. روی GitHub Pages هم بدون تنظیم اضافی کار می‌کند.
